# Archive

Older material moved here on 2026-10-13. The current reader and maintenance tools
do not use these files. All 123 moved files retain their original contents.

- `BK/`: previous readers, converters, JSON backups, and the earlier Anexo 5 viewer
  in `BK/anexo5_visor_previo/`.
- `example_files/`: saved example page and its supporting files.
- `anexo_no._5_manual_comunes_tramientos_urbanisticos_.html`: earlier Word export
  of Anexo 5, preserved for comparison with the official updated PDF.
- `anexo_no._5_manual_comunes_tramientos_urbanisticos__files/`: the Word export's
  images and supporting files, kept beside its HTML to preserve relative paths.

The current official Anexo 5 PDF is in `../anexos/anexo_05_actualizacion/`.
